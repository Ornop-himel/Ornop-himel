## 🚀 Featured Project

### 🖤 KAIVORN — Full-Stack E-commerce Platform

A modern streetwear e-commerce project featuring a shopping
experience, user accounts, order management and an admin dashboard.

**Key Features**
- 🛒 Product browsing, search, categories and product details
- 🔐 User registration, login and JWT authentication
- ❤️ Shopping cart and wishlist
- 📦 Checkout, order history and order tracking
- 🛠️ Admin dashboard for products, orders and customers
- 📊 Sales analytics, revenue charts and inventory alerts
